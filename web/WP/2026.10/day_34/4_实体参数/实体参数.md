# [靶场地址](https://portswigger.net/web-security/xxe/blind/lab-xxe-with-out-of-band-interaction-using-parameter-entities)

### 关于本题
1. 实体参数:
```
<!DOCTYPE root_element[<!ENTITY % rule '<ELEMENT root_element (#PCDATA)>'> %rule;]>
<root_elemrnt>hello</root_element>
```
   - % 　: %表示rule是一个实体参数
   - rule　: 实体的名称
   - ''里的内容　:实体展开后将成为一条的DTD声明
   - %rule　: 和前面 *&greeting* ; 一样
   - #PCDATA　: parsed Character Data,解析后的字符数据;普通文本和可展开的实体引用都属于这一类
        - hello属于普通文本,满足这一规则
本题的关键是让*实体参数在DTD内被声明并触发解析*
